# Brag Plan: OpenDeX 🌌

## What is this app?
OpenDeX is a Knox-free, vendor-unlocked open-source desktop environment for Android that turns any phone into a multi-window workstation using native AOSP Windowing Mode 5.

## The angle
The \$1,000 Android tablet experience, unlocked on any phone for free. No proprietary hardware chips, no Knox lock-in, no root permissions. Pure native AOSP multi-window computing with resizable floating apps, virtual workspaces, and persistent overlay navigation.

## Hook (first 2-3 seconds)
Deep obsidian abyss with radiant cyan and magenta cosmic flares. Giant typography slams in: "SAMSUNG CHARGES $800 FOR THIS." Beat drops, glowing text flips: "WE JUST MADE IT FREE FOR EVERY ANDROID PHONE."

## Key moments (the middle)
1. **The Desktop Canvas:** Full 1920x1200 landscape desktop with Living Clock widget, Celestial Hyper Space wallpaper, and unified squircle dock icons.
2. **AOSP Freeform Multi-Window & Snap:** Floating apps running side-by-side with 50/50 split snapping, drag-repositioning, and titlebar window controls.
3. **Virtual Desktops & Task View:** 1-finger horizontal workspace slide transitions, centered HUD badge, and 1-tap window management with instant close buttons.

## Outro / punchline
"Zero Knox. Zero Root. 100% Native AOSP." Pulsing OpenDeX glyph, star count callout, and GitHub repo badge.

## User flow worth showing
Entry on external monitor -> 9-dot App Drawer launch -> Floating browser & documents snap 50/50 -> Swipe between virtual desktops.

## Storyboard

### Scene 1 — The Hook — 3.2s
- **Visual:** Obsidian void with blooming cyan nebulae. Text animates in: "THE $800 TABLET FEATURE." Strikethrough flashes red: "NOW UNLOCKED FOR EVERY ANDROID PHONE."
- **Sequential:** High-contrast title slam -> Glowing badge reveal.
- **Audio intent:** Sub bass riser building up to beat drop.
- **Transition:** Light flash zoom -> Scene 2.

### Scene 2 — The Pure Desktop Canvas — 5.0s
- **Visual:** Smooth camera push into the OpenDeX desktop. 64sp Living Clock reads "12:22 Thursday, November 19", Celestial Hyper Space radial flares glow, and dock icons animate across the bottom in unified squircle frames.
- **Sequential:** Desktop clock appears -> Dock slides up -> 9-dot launcher glows.
- **Audio intent:** Rhythmic beat groove with clean hi-hats.
- **Transition:** Smooth pan to center -> Scene 3.

### Scene 3 — Freeform Windows & 50/50 Split Snap — 5.3s
- **Visual:** Settings and Browser windows pop up simultaneously in floating mode. Cursor drags Browser to the left edge: window smoothly snaps into Left 50% half. Settings snaps into Right 50% half. Real simultaneous execution.
- **Sequential:** Window 1 opens -> Window 2 opens -> Edge drag snap animation.
- **Audio intent:** Snappy tactile click on window docking.
- **Transition:** Horizontal parallax slide -> Scene 4.

### Scene 4 — Virtual Desktops & Task View — 3.5s
- **Visual:** 1-finger horizontal swipe triggers smooth workspace transition. Desktop slides horizontally with parallax wallpaper shift; centered glassmorphic HUD badge "Desktop 2" pops up. Task View opens showing running window cards with "X" close buttons.
- **Sequential:** Slide transition -> Workspace HUD -> Task View card expansion.
- **Audio intent:** Whoosh transition with soft chime.
- **Transition:** Fade into brand lockup -> Scene 5.

### Scene 5 — Outro & Open Source Call to Action — 3.0s
- **Visual:** OpenDeX glowing galaxy glyph. Headline: "OpenDeX — Zero Knox. Zero Root." Call to action: "Open Source on GitHub | Download APK".
- **Sequential:** Logo expands with cyan glow -> GitHub star counter shines.
- **Audio intent:** Reverb tail fade out.
